编者观察
今天的核心是可核验性。Claude Code 的 Don't Ask Again 让 1,122 个公开 GitHub 文件出现口令，一份 TOML 清单要求跳过任一行即非零退出：授权要可撤销、闸门要能自己失败。对 WorkBuddy 的 skill 与 MCP 开关就是默认可撤销；本流水线已有三关验证与 verify_digest 零 violations，却缺删项后退出码的反面测试。

第二条线是编排不是模型。斯坦福 CS 329Z 把框架与编排单独排到第5讲，Claude 把穹窿体提纯从 3 天压到 90 分钟，增益都来自流程重排而非更大的模型。对 WinVM Bridge 的 A2A streaming 委派，先把谁在何时接管写成可观测状态，否则进度只是日志不是控制权；skill 分层同理，工具注册与编排同处一模块就该拆开。

第三条线是底层数据。Ling-3.2-flash 的 1M token 上下文、Pallatom2 开源序列与 BLI 图谱、MBARI 首次 4K 影像，都让下游不必替上游补洞。这正是确定性脚本做索引、AI 只做研判的前提：摘要只剩 Comments 就拒绝入报，不放宽阈值，被剔除条目进 no-number 待补清单，补摘要或换一手来源，绝不动 content-spec。下一步只做一件可证伪的事：给闸门补一条删除检查项后的退出码断言。
