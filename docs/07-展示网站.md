# 07 · 简约清新的信息展示网站

> **v3 更新（2026-11-06）**：新增「日期 / 分类」双维导航——日期默认打开最新、首项带「最新」标记；
> 分类按当日 `digest.sections` 动态生成并带条数，点击筛选 + 平滑定位；两个维度写进 URL hash 可分享。
> 订阅入口改为**引导面板 + 一键复制绝对地址**，顶栏与页脚都不再直跳 `.atom` 源码页。
> 真实浏览器双场景验收 16/16，见 `reports/site-ui-check-2026-11-06.md`。

> **v2 更新**：卡片现在展示七要素（事实锚点、数字 chips、相关方、为什么值得看、
> 对我意味着什么、下一步动作），链接独立成行 `→ https://…`（借鉴 daily-rss 2026-11 改版），
> 并新增「待验证信号」与「今日数据概览」两个表格区块。数据契约见 `config/content-spec.json`。

> 成品：`public/index.html`（单文件，零依赖、零构建、零 CDN）+ `public/data/*.json`。
> 数据由 `scripts/build_site.py` 从 digest.json 幂等投影，做到「改数据不改代码」。

## 1. 设计目标

| 目标 | 做法 |
| --- | --- |
| 简约清新 | 中性冷灰底 + 大留白 + 细边框 + 单一石板蓝点缀色；无渐变、无动效堆砌、无广告位 |
| 一眼看懂今天 | 首屏 Hero：日期 / 标题 / 徽标 / 5 个统计数字（入报条目、板块、主线、簇、信源可用） |
| 先主线后细节 | 今日主线卡片网格（每条注明佐证条目数）→ 分类聚合卡片列表 |
| 可追溯 | 每条卡片显示来源、发布时间、分数、分类、原文链接，标题本身也可点开原文 |
| 可回溯 | **日期维度**：顶部横向日期导航，默认 `dates[0]`（最新）并标「最新」，点击切换到 `<date>.json`，历史永久可读 |
| 可聚焦 | **分类维度**：按当日 `digest.sections` 动态生成分类条（带条数），点击只渲染该分类并定位；与搜索叠加（AND） |
| 可分享 | 日期 + 分类写进 URL hash（`#date=YYYY-MM-DD&cat=<key>`），刷新不丢；切日期自动清空分类 |
| 可检索 | 前端即时搜索（标题 / 来源 / 摘要 / 研判 / 分类），无需后端 |
| 可订阅 | 引导面板解释 `.atom` 是阅读器用的源文件，给出绝对地址 + 一键复制；保留 `rel=alternate` 自动发现 |
| 深浅自适应 | **深色为默认**（`<html data-theme="dark">`，首帧不闪白），右上角一键切浅色并记住选择；CSS 变量统一配色 |
| 零运维 | 纯静态文件，发布为网站即用；无 API、无数据库、无 SSR |

## 2. 视觉规范（CSS 变量）

> **v3.1 配色修订（2026-11-06）**：原「墨绿系」深浅两套都让绿色通道成为主导通道
> （如 `#151a17` / `#1d241f` / `#79c8a2`），整页泛绿。现统一为**中性冷灰 + 石板蓝**，
> 并规定所有中性色满足 `G <= max(R, B)`；`check_release.py` 逐色校验防止回退。
> 默认主题由浅色改为深色。

| 变量 | 浅色 | 深色（默认） | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#f7f8fa` | `#111418` | 页面底 |
| `--surface` | `#ffffff` | `#181d23` | 卡片 / 顶栏 |
| `--surface-2` | `#f1f3f6` | `#20262e` | 次级块 / 日期 chip |
| `--line` | `#e3e7ed` | `#2d3540` | 细边框 |
| `--ink` | `#1d232b` | `#eef1f5` | 主文字 |
| `--ink-2` / `--ink-3` | `#586371` / `#8a949f` | `#a9b2bd` / `#7c8693` | 次要 / 弱化文字 |
| `--accent` | `#3b6d9e` | `#8fb9e0` | 石板蓝：链接、徽标、分数 |
| `--accent-soft` | `#e9f0f8` | `#1c2a38` | 选中态 / 徽标底 |
| `--warn` / `--warn-soft` | `#b26a3d` / `#fbf0e7` | `#e0a97c` / `#3a2c20` | 降级 / 演示数据提示 |
| 遮罩 / 阴影 | `rgba(28,40,55,…)` | `rgba(0,0,0,…)` / `rgba(12,16,21,.62)` | 同样不泛绿 |

- 字体：系统字体栈（`-apple-system / Segoe UI / PingFang SC / Microsoft YaHei`），不加载 Web Font；
- 圆角 14px、极轻阴影、行高 1.7、正文 15px；
- 卡片 hover 只改边框色与浅阴影，不做位移动画；
- 移动端：Hero 与网格自动降为单列，横向日期条可滑动。

## 3. 页面结构

```
<header>
  ├ 品牌「每日信息」+ 副标题「挖掘 · 聚合 · 研判 · 订阅」
  ├ 搜索框（即时过滤）
  ├ 深色/浅色切换
  ├ 订阅 RSS 按钮 → 订阅引导面板（不直跳 .atom）
  ├ 日期导航（横向 chips，来自 index.json.dates；默认最新）
  └ 分类导航（来自当日 digest.sections，带条数，点击筛选 + 定位）
<main>
  ├ Hero：kicker(日期) / headline h2 / 徽标(已核验·ai_status·演示数据)
  │        / 生成时间 / stats 五宫格
  ├ 今日主线：网格卡片（序号、标题、why、佐证条目数）
  ├ 分类聚合：按 section 分组，每条卡片
  │   ├ 标题（链接原文，target=_blank rel=noopener noreferrer）
  │   ├ 为什么值得看
  │   ├ 原文摘要（两行截断）
  │   └ foot：来源 / 发布时间 UTC / 分数 / 分类 / 原文 ↗
  └ 编者观察（左边框强调块）
<footer>
  ├ 免责声明（未独立验证 / 不构成投资建议 / 暂无可靠数据）
  └ 5 个订阅 profile 按钮（点击打开引导面板并定位到该频道）
订阅引导面板（modal，默认隐藏）
  ├ 说明「浏览器打开 .atom 会显示 XML 源码，请复制到阅读器」
  ├ 5 个频道的绝对地址（new URL(f.url, location.href)）+ 一键复制
  └ 次级链接「查看源文件（会显示 XML）」+ JSON Feed 地址
```

## 4. 数据契约

| 文件 | 内容 | 生成者 |
| --- | --- | --- |
| `public/data/index.json` | `site` 元信息、`dates[]`（date/headline/demo/stats/section_count/item_count/ai_status）、`feeds[]` | `build_site.py` |
| `public/data/latest.json` | 最新一天完整 digest | `build_site.py` |
| `public/data/<date>.json` | 该日完整 digest（与事实源同内容） | `build_site.py` |
| `public/data/feeds.json` | 5 个 profile 的 URL / filter / 条目数 | `build_feeds.py` |

前端只读这些文件：**不内联数据、不调用任何后端、不依赖第三方库**。
所有外部文本经 `esc()` 转义后再插入 DOM，防 XSS；原文链接统一 `noopener noreferrer`。

## 5. 交互

| 交互 | 实现 |
| --- | --- |
| 切换日期 | 点击 chip → `fetch('data/<date>.json')` → 重建分类条 + 重渲染；清空分类筛选；hash 同步 |
| 默认视图 | 无 hash 时 `idx.dates[0].date`（最新），首项带「最新」标记 |
| 分类筛选 | 点击分类 chip → `state.cat` → 只渲染该 section 并 `scrollIntoView` 平滑定位；hash 同步 |
| 搜索 | `input` 事件 → 前端过滤 items → 只重渲染列表；与分类筛选 AND 叠加；无匹配显示提示 |
| URL hash | `#date=...&cat=...` 用 `history.replaceState` 同步；`hashchange` 支持手动改地址 |
| 主题切换 | `<html data-theme="dark">` 保证首帧即深色；`<head>` 内联脚本读 `localStorage('daily-info-theme')`，仅当显式切过浅色时改成 `light`（try/catch 兜底，隐私模式 / `file://` 回落深色）；按钮点击写回并同步文案与 `aria-label` |
| 订阅 | 顶栏按钮 / 页脚 5 个频道 → 打开 modal（遮罩点击、×、ESC 关闭）；展示绝对地址 + 一键复制（`navigator.clipboard`，`execCommand` 兜底） |
| 加载失败 | 显示明确错误 + 提示「请通过本地 HTTP 服务访问，不要直接双击 file://」 |

**降级 / 演示态可见**：`ai_status=degraded` 时 Hero 徽标显示「降级出报」；
`demo=true` 时额外显示「演示数据」橙色徽标，防止把 smoke 数据误当真实日报。

## 6. 部署

```bash
# 本地预览（Windows 必须用 localhost，不要用 127.0.0.1）
python -m http.server 8765 --directory public
# → http://localhost:8765/
```

- 本机 NekoBox 为 TUN 模式，会拦截直连 IPv4 `127.0.0.1` 的裸 TCP；
  `localhost` 解析到 IPv6 `::1` 通常不受拦截。脚本可另设 `NO_PROXY=localhost,127.0.0.1`。
- 在线发布：在 WorkBuddy 中对 `public/` 使用「发布为应用 / 发布为网站」得到在线链接；
  发布为网站会同时把页面存入资料库，便于跨设备访问。
- 每次日报生成后 `build_site.py` 幂等写入；内容未变不重写文件，不触发无谓的重新发布。
- 也可推到 GitHub Pages / 任意静态托管；站点不依赖 WorkBuddy 运行时。

## 8. 与参考仓库对照

| 参考仓库 | 展示方式 | 本方案 |
| --- | --- | --- |
| daily-rss | 只有 GitHub 渲染的 Markdown 日报 | 结构化站点 + 日期归档 + 搜索 + 分类视图 |
| blogpost | GitHub 仓库 + 手工生成的 README 索引（328 链接 vs 333 文章） | `index.json` 由脚本确定性生成，永不漂移 |
| daily-investor | 纯 Markdown 长文，4 种目录格式 | 统一 schema，站点按日期一致渲染 |
| docs-feed | 只有 Atom，无 HTML 站点 | 站点与订阅同源投影，互不重复维护 |

## 9. 可扩展但不默认做

- 时间线视图（日期 + 分类双维导航已在 v3 落地，足够覆盖回溯需求）；
- 趋势图（等真实数据积累 2–4 周后再加，避免 demo 阶段画出误导性图表）；
- 阅读状态标记（需 localStorage 或云服务，与个人系统「零状态」取舍冲突）；
- 多语言界面（当前全中文，符合用户偏好）。
